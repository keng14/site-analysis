# Site Analysis · แดด ลม ผังเมือง

เว็บแอปวิเคราะห์ไซต์สำหรับสถาปนิกและเจ้าของบ้าน ใช้ได้ทั้ง PC แท็บเล็ต และมือถือ รองรับภาษาไทย / English

🔗 **เปิดใช้งาน:** https://keng14.github.io/site-analysis/

## ขั้นตอนการใช้งาน
1. **วิธีใช้:** วางพิกัดหรือลิงก์จาก Google Maps หรือเลือกสร้างรูปแบบเอง
2. **ผังเมือง:** อ่านเขตสีจากแผนที่ผังเมือง กทม. ดู FAR/OSR ว่าสร้างอะไรได้ สูงได้แค่ไหน และระยะร่นจากถนนกับแหล่งน้ำ
3. **ออกแบบ:** วิเคราะห์แดด ลม ผนังร้อน โซลาร์เซลล์ แล้วส่งออกแผ่นนำเสนอ

## ฟีเจอร์
- **แดด:** ทางเดินดวงอาทิตย์ 3D และผัง 2D, เงาตามเวลา, แผนที่ชั่วโมงแดดบนพื้น, มุมมองจากดวงอาทิตย์
- **ลม:** wind rose แยกตามฤดูและรายเดือน มีเส้นลมไหลอ้อมตัวอาคาร ใช้ข้อมูลจริงจาก Open-Meteo ได้
- **ผนัง:** จัดอันดับความร้อนของผนัง และแนะนำความลึกกันสาดหรือแผงบังแดด
- **โซลาร์:** ทิศและมุมติดตั้ง หักเงาจากต้นไม้และอาคารข้างเคียงทีละแผง และประมาณ kWp กับ kWh ต่อปี
- **ผังเมือง:**
  - อ่านรหัสสีอัตโนมัติจากระบบแผนที่ของสำนักการวางผังและพัฒนาเมือง กทม.
  - FAR/OSR ตามผังเมืองรวม กทม. 2556 และมวลอาคารสูงสุดที่สร้างได้
- **ระยะร่น:** ตามกฎกระทรวง 33 และ 55 จากเพื่อนบ้าน ถนน คลอง และบึง/ทะเล ตรวจหาถนนกับแหล่งน้ำจาก OpenStreetMap ได้
- **บริบทรอบข้าง:** อาคาร ต้นไม้ ถนน และแหล่งน้ำจริงจาก OpenStreetMap
- **ส่งออก:** แผ่นนำเสนอ PNG มีภาพเงา 6 ช่วงเวลา ผังลม และสรุปกฎหมาย

## ⚠️ ข้อควรทราบ
ทุกค่าในแอปเป็นการประมาณเพื่อการออกแบบเบื้องต้น ก่อนยื่นขออนุญาตก่อสร้างควรตรวจกับข้อบัญญัติท้องถิ่น ผังเมืองรวมฉบับที่ใช้บังคับ และให้สถาปนิกหรือวิศวกรผู้มีใบอนุญาตตรวจสอบ ผังเมืองรวม กทม. ฉบับปรับปรุงครั้งที่ 4 คาดว่าจะประกาศใช้ปี 2570
